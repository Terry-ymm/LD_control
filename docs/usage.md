# 使用说明

## 运行环境

- 操作系统：建议 Windows。
- Python：建议 3.10 或更高。
- 主要依赖：`pyserial`、`numpy`、`scipy`、`osqp`。
- 主程序目录：`MPC_fixed`。

本工作副本已附带配置好的 `.venv`（含全部依赖）。**直接用项目 `.venv` 运行**，不要用 `python`/`py`，也不要重建 `.venv`（本机 `python -m venv` 不可用，`.venv` 只能整体复制）。

```bat
cd E:\dsharness\新控制代码
.venv\Scripts\python.exe MPC_fixed\main.py
```

无硬件算法自检：

```bat
.venv\Scripts\python.exe MPC_fixed\mpc_controller.py
```

## 串口连接

启动 GUI 后，先点击“刷新端口”，再选择对应 COM 口。

默认波特率：

| 设备 | 默认波特率 |
| --- | --- |
| 倾角传感器 | 230400 |
| 4 条调平腿电动缸 | 115200 |
| 方位控制器 | 115200 |
| 举升电动缸 | 115200 |
| 俯仰角度编码器 | 115200 |

连接建议顺序：

1. 倾角传感器。
2. 四条调平腿。
3. 方位控制器。
4. 举升电动缸。
5. 俯仰角度编码器。
6. 启动反馈轮询，确认角度、位置和状态字刷新正常。

## 上硬件前检查

在 `IDLE` 模式下完成以下低速验证：

1. 调平四腿单独动作：确认腿编号、上行/下行方向、停止命令有效。
2. 方位轴：先故障复位、使能，再用极低 rpm 验证逆时针/顺时针方向。
3. 举升/俯仰：用低 rpm 验证电缸方向，再用小目标角速度验证前馈 PID 方向。
4. 置零：确认方位角、俯仰角和调平当前位置置零结果符合实验定义。
5. 全部停止：确认点击“全部停止”后所有执行器停止。

手动调试按钮要求总控处于 `IDLE`。如果当前处于本地调平或 MPC，需要先停止控制循环或全部停止。

## 本地调平

本地调平只使用倾角传感器和四条调平腿，不包含原独立调平程序中的触地和预顶升阶段。

步骤：

1. 连接倾角传感器和 4 条调平腿。
2. 启动反馈轮询。
3. 点击“重置调平起点”。
4. 点击“启动本地调平阶段”。
5. 观察 X/Y 倾角、四腿 rpm 和位置变化。
6. 完成或异常时点击“全部停止”。

主要参数可以在界面中设置：

- `Kp`：姿态调平比例系数。
- `死区`：角度误差死区，当前默认 `0.002 deg`。
- `抗扭增益`：四腿扭转误差修正。
- `最大 rpm`：调平腿电机速度限幅。
- `维持时间`：进入死区后保持多久判定完成。

## MPC 总控

MPC 总控会同时使用调平、方位、举升/俯仰系统。启动前建议至少完成手动低速验证、反馈轮询和必要置零。

步骤：

1. 连接需要参与实验的设备。
2. 启动反馈轮询。
3. 确认倾角、方位角、俯仰角反馈稳定。
4. 必要时做方位角置零、俯仰角置零、调平位置清零。
5. 点击“启动MPC总控”。
6. 程序会弹出 CSV 保存窗口；选择保存文件后才启动，取消则不启动。
7. 实验中观察状态栏、CSV 日志、俯仰角、方位状态字、MPC 求解状态。
8. 实验结束或异常时点击“全部停止”。

MPC 默认目标轨迹由 `target_trajectory.py` 给出：先把俯仰角推进到 `60 deg`，约 `20 s` 后开始方位运动。需要改变实验目标时，优先修改 `TargetTrajectory` 的参数或生成逻辑。

## CSV 记录

MPC 启动要求 CSV 记录已开启。日志字段包括：

- 时间戳、运行模式、停止原因。
- 倾角 X/Y/Z。
- 方位命令 rpm、反馈 rpm、方位角、状态字。
- 举升命令 rpm、俯仰角、俯仰角速度。
- MPC 四通道输出、求解状态、求解器消息。
- 未来 3 步目标向量。
- 四条调平腿连接状态、命令 rpm、位置。

CSV 使用 `utf-8-sig` 编码，便于 Excel 直接打开。

## 停止与异常处理

- “全部停止”：取消控制循环，停止调平、方位和举升，并停止 CSV 记录。硬件异常时优先使用。
- “停止控制循环”：停止循环和记录，但提示中明确说明不自动下发全部零速。
- 俯仰角达到 `69 deg` 或更高时，反馈线程会停止举升；如果正在控制循环中会触发全部停止。
- 俯仰角低于 `40 deg` 时，MPC 方位输出会被总控强制置零。
- 举升最低限位（软限位）：在 `IDLE` 下连接俯仰编码器后点击"设为最低限位"，以当前原始俯仰角为基准在其上方 `0.05°` 设限；俯仰角处于限位及以下时只准上升、禁止下降，点击"清除"可取消。软件"角度置零"不影响该限位。
  - 该限位会**持久化**到 `MPC_fixed/lift_min_limit.json`，程序重启后自动加载（连上俯仰编码器读到有效位置后即生效），无需每次重设；"清除"会同时删除配置文件。
- MPC 连续求解失败 3 次会停止。

## 修改 MPC 的入口

主要修改点在 `MPC_fixed/mpc_controller.py`：

- 修改权重：`Q_weight`、`R0`、`P0`、`P_scale`。
- 修改速度限幅：`vel_max_deg_s`。
- 修改角度限位：`pos_min_deg`、`pos_max_deg`。
- 修改控制增量限幅：`delta_u_limit_deg_s`。
- 修改采样周期：`T`，同时要保证总控界面的 MPC 周期一致。

目标轨迹修改点在 `MPC_fixed/target_trajectory.py`。

执行器换算修改点：

- 调平四腿分配：`LevelingExecutor.tilt_rate_to_leg_rpm()`。
- 方位角速度到 rpm：`AzimuthExecutor.set_azimuth_rate()` 和 `motor_gear_ratio`。
- 俯仰角速度到电缸 rpm：`LiftExecutor.pitch_gain_table` 和 PID 参数。
