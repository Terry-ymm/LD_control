# 举升缸位置闭环驱动（点到点）

在 `06 - 开环目标俯仰角验证` 的基础上，实现举升缸俯仰角的**闭环位置驱动**：
输入目标俯仰角，程序自动规划梯形速度曲线并驱动到位、自动停住。

## 1. 控制架构

采用级联控制，复用已有的速度环：

```
目标俯仰角(deg)
      │
      ▼
┌─────────────────────────────────────────────┐
│ 位置环  lift_position_controller.py（纯计算） │
│   梯形速度曲线规划（最大速度/加减速度）          │
│   + 位置 P(I)(D) 校正（跟踪误差）              │
│   + 速度前馈（曲线参考速度）                    │
│   → 输出：目标角速度 deg/s                     │
└─────────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────────┐
│ 速度环  LiftExecutor（已有，前馈+角速度PID）   │
│   pitch_velocity_pid_to_lift_rpm()           │
│   → 输出：电机转速 rpm                        │
└─────────────────────────────────────────────┘
      │
      ▼
   0x3308 速度帧 → 举升电动缸
```

位置环输出 `目标角速度 deg/s`，速度环照旧做前馈 + 角速度 PID 并换算为 rpm。
方向系数 `pitch_lift_direction`、软限位、增益表都在速度环/执行器层统一处理，位置环与方向约定解耦。

## 3. 运行方式

本项目依赖的 `osqp` 只装在项目 `.venv` 里（系统 Python 缺 `osqp`），请用 `.venv` 运行：

```bat
cd E:\dsharness\新控制代码
.venv\Scripts\python.exe MPC_fixed\lift_07_position_drive.py
```

> 说明：`py` 启动器指向的系统 Python 缺 `osqp`，主控 `main.py` 必须用 `.venv`；
> 独立测试窗口 `lift_07_position_drive.py` 不依赖 `osqp`，两种方式均可。

### 方式一：独立测试窗口 `lift_07_position_drive.py`

1. 运行后先“刷新 COM 口”，分别连接举升电动缸与俯仰角度编码器（两个不同 COM）；
2. 点“开始本阶段 CSV”开始记录；
3. 勾选安全联锁（确认机械活动区域、急停、人员站位安全）；
4. 输入目标俯仰角与位置环参数（默认已经很保守），点“开始位置运动”；
5. 观察“位置环状态 / 目标角速度 / 曲线参考速度”，到位后自动停止并写入 CSV。

### 方式二：总控 `main.py`（IDLE 手动）

1. 连接举升电动缸 + 俯仰角度编码器，启动反馈轮询；
2. 确保当前模式为 `IDLE`；
3. 在“举升/俯仰系统”面板底部的“位置闭环驱动（点到点）”区域输入目标角，点“开始位置驱动”；
4. “全部停止/急停”会同时复位位置环并下发 0。

## 4. 位置环参数

| 参数 | 单位 | 默认 | 说明 |
|---|---|---|---|
| 目标俯仰角 | ° | 10.0 | 到位目标，超软限位会被钳制 |
| 最大角速度 `max_vel_deg_s` | deg/s | 0.5 | 梯形曲线巡航速度，保守起步 |
| 加速度 `accel_deg_s2` | deg/s² | 1.0 | 升速斜率 |
| 减速度 `decel_deg_s2` | deg/s² | 1.0 | 减速斜率 |
| 位置环 `kp` | deg/s per deg | 5.0 | 比例增益，越大越“硬” |
| 位置环 `ki` | — | 0.0 | 积分（默认关，抗重力保持时才开） |
| 位置环 `kd` | — | 0.0 | 微分（默认关） |
| 到位死区 `deadband_deg` | ° | 0.05 | 连续 N 拍在死区内判定到位 |
| 输出限幅 `max_output_deg_s` | deg/s | 1.0 | 目标角速度上限 |
| 跟随误差保护 `follow_error_limit_deg` | ° | 3.0 | 跟踪误差超限自动停机 |

## 5. 安全机制

- **保守默认速度**：默认最大角速度 0.5 deg/s（约 150~250 rpm），远低于 2200 rpm；
- **软限位**：目标角钳制在 `-0.02° ~ 65°`（与 MPC 举升角限制一致）；
- **最低限位**：复用速度环的“只准上升、禁止下降”软限位；该限位持久化到 `MPC_fixed/lift_min_limit.json`，重启自动加载（`lift_07` 窗口新增“设为最低限位/清除”按钮），无需每次重设；
- **跟随误差保护**：位置环跟踪误差超过 3° 立即下发 0 停机；
- **停机路径**：到位 / 故障 / 反馈丢失 / 断开连接 / 急停，均复位位置环并下发 0。

## 6. 离线自测结果（无硬件，虚拟电动缸）

虚拟电动缸用一阶速度环近似 + 真实前馈增益表，闭环自测结果：

| 场景 | 结果 |
|---|---|
| 正向 0 → 20° | 到达，约 10.9 s，误差 +0.0012° |
| 反向 20 → 5° | 到达，约 8.4 s，误差 -0.0016° |
| 大行程 0 → 40° | 到达，约 20.9 s，误差 +0.0010° |
| 卡死保护 0 → 30°（角度冻结） | 1.65 s 触发跟随误差停机 |
| 软限位 目标 80° / -10° | 正确钳制为 65.0° / -0.02° |

## 7. 现场调参建议

1. **先验证方向**：用最小角速度做一个小角度点动，确认角度增大/减小与目标一致；
2. **先慢后快**：默认 0.5 deg/s 起步，确认到位精度后逐步提高 `max_vel_deg_s`；
3. **到位精度**：到位后若振荡，先降 `kp` 或增大 `deadband_deg`；若稳态偏差大，再考虑加 `ki`；
4. **全程观察**：跟随误差若持续逼近 3°，说明速度环跟不上，应降低 `max_vel_deg_s`。
