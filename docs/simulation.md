# 无硬件 MPC 指向仿真

`MPC_fixed/simulation.py` 是一个不连接传感器、不打开串口、不向执行器下发命令的离线仿真入口。它复用当前 `MPC_fixed/mpc_controller.py` 中的 MPC 求解器，并用一个带一阶执行器惯性的虚拟机构代替真实调平腿、方位轴与举升机构。

## 启动

在 CMD 中，从仓库根目录运行：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\simulation.py"
```

在 PowerShell 中运行：

```powershell
& .\.venv\Scripts\python.exe .\MPC_fixed\simulation.py
```

依赖与主程序相同：`numpy`、`scipy`、`osqp`。本仿真不需要连接串口设备。

## 使用

1. 设置初始调平 X/Y 倾角、初始方位角和初始俯仰角。
2. 输入目标单位向量 `[Rx, Ry, Rz]`；可以用逗号或空格分隔，程序会自动归一化。
3. 点击“重置为设定值”，确认当前和目标向量。
4. 点击“开始仿真”。
5. 观察调平 X/Y、方位、俯仰、MPC 输出、指向误差、方向投影和最近 30 秒的角度曲线。

默认目标 `0, 0.866025, -0.5` 对应约 `60°` 俯仰、`0°` 方位的阵面方向。

## 约束与模型含义

- 调平 X/Y 虚拟机械限位为 `±2°`，俯仰限位为 `-0.02°` 至 `65°`，与当前 MPC 默认限位一致。
- 超出 `65°` 俯仰可达范围的目标向量会在重置时被拒绝。
- 方位不设置软件角度限位。
- 虚拟机构通过一阶惯性（时间常数 `0.35 s`）跟随 MPC 输出；这用于观察闭环响应，不是已标定的真实机械模型。
- 实际硬件的传动比、摩擦、间隙、俯仰前馈表和传感器噪声没有在这个第一版仿真中建模。因此仿真收敛只能证明 MPC 的软件链路和坐标约定在该虚拟模型中自洽，不能替代实机低速验证。
