# 举升缸 / 俯仰角度实机测试说明

## 目的和范围

本说明对应 `MPC_fixed/lift_00_usb_connection_check.py` 至 `lift_06_open_loop_angle.py`。七个程序相互独立：每个窗口只做本阶段测试，只生成本阶段 CSV，不会启动 MPC、总控或其他测试阶段。

测试程序复用当前项目已经使用的举升缸速度帧、电机编码器读取和俯仰编码器读取协议，但不修改 `master_controller.py`、`mpc_controller.py` 或正常硬件运行入口。

> 警告：USB 只是通信链路，不能替代硬件急停。任何测试前都必须确认独立急停、机械活动区域、载荷和人员站位安全。出现异常时优先使用独立急停，其次点击 GUI 的“立即停止 / 急停”。

## USB 与 COM 口连接

本项目当前举升测试假设使用两条独立的 USB 转串口链路：

| 设备 | 物理连接 | 程序中的字段 | 当前源码默认波特率 |
| --- | --- | --- | --- |
| 举升电动缸驱动器 | 驱动器通信口 → USB 转串口/USB 转 RS485 → 电脑 | 举升缸 COM | 115200 |
| 俯仰角度编码器 | 编码器通信口 → USB 转串口/USB 转 RS485 → 电脑 | 俯仰编码器 COM | 115200 |

接线和识别顺序：

1. 设备断电，检查动力线、通信线、编码器线、屏蔽和独立急停；不要仅依赖 USB 拔插停机。
2. 接通控制电源和两条 USB 转串口线。
3. 打开 Windows **设备管理器 → 端口(COM 和 LPT)**，记录两个新增的 COM 号和设备描述。
4. 依次拔掉一条 USB 再刷新设备管理器，确认哪个 COM 对应举升缸、哪个对应俯仰编码器。
5. 在程序中选择两个不同的 COM 号；如果只显示一个或没有 COM 口，停止测试，检查 USB 驱动、供电和转换器类型。

当前程序沿用下列源码假设，接线/设备升级后必须重新确认：

- 举升缸速度命令：已验证的 `0x3308` 速度帧。
- 举升缸电机编码器：保持寄存器 `0x4202`，2 个寄存器。
- 俯仰编码器：保持寄存器 `0xF010`（对应 CiA402 `0x6064`），2 个寄存器。
- 电机编码器的 `5 mm` 丝杠导程和 `5:1` 减速比仅用于显示 mm；若机械参数不同，标定前不得相信该 mm 数值。

## 环境与启动

以下命令适用于 **CMD**（提示符形如 `D:\...>`）：

```cmd
cd /d "E:\dsharness\新控制代码"
".venv\Scripts\python.exe" "MPC_fixed\lift_00_usb_connection_check.py"
```

每次只启动一个程序。其余阶段替换脚本名：

```text
lift_01_encoder_feedback_check.py
lift_02_low_speed_jog.py
lift_03_safe_stroke_measure.py
lift_04_speed_characterization.py
lift_05_min_increment.py
lift_06_open_loop_angle.py
```

运行时先点击“刷新 COM 口”，再分别连接举升缸和俯仰编码器。运动程序（02 至 06）必须先点击“开始本阶段 CSV”，并勾选机械安全确认，才允许发送速度命令。

## 共同界面和安全规则

每个窗口都有相同的连接区和实时反馈区：

- **电机编码器 / 缸位移**：原始单圈计数和相对 mm；首次有效读取会作为当前软件零点。
- **俯仰编码器 / 俯仰角**：原始计数和软件相对角度；使用“俯仰角清零”可把当前姿态设为 0°。
- **电机位移清零**：只影响当前测试会话中的相对位移显示，建议在行程标定开始位置使用。
- **立即停止 / 急停**：连续发送三次零速。它不是独立硬件急停的替代品。

测试实例中的安全限制：

- 最大命令速度：`100 rpm`。
- 默认速度：`20 rpm`。
- 默认单脉冲时长：`0.5 s`。
- 单次脉冲硬上限：`2.0 s`。

第一次点动建议从低于默认值的速度和小于 `0.5 s` 的时长开始。正/负 rpm 只表示通信方向，在未完成方向确认前，不得把它称为“上升/下降”。

如果出现读数无效、超过 1 秒未得到两路有效反馈、串口异常、窗口关闭或手动急停，程序会停止当前输出。若机械仍在运动，立即使用独立急停并断开动力回路。

## 00 - USB / COM 连接检查

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_00_usb_connection_check.py"
```

操作：

1. 点击“刷新 COM 口”，记录显示的 `COMx: 设备描述`。
2. 通过拔插单个 USB 转串口，确认两个设备的 COM 映射。
3. 分别连接两个设备，但本程序不发送电机速度命令。
4. 如需留下连接记录，点击“开始本阶段 CSV”。

通过条件：两个 COM 号稳定、可单独识别；程序连接时无异常。若端口会变化，先固定 USB 插孔并重新记录。

## 01 - 电机与俯仰编码器反馈检查

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_01_encoder_feedback_check.py"
```

操作：

1. 连接两路设备，确认“电机反馈：有效；俯仰反馈：有效”。
2. 点击“开始本阶段 CSV”。
3. 保持机构静止，点击“开始 30 s 稳定性记录”。
4. 记录完成后查看电机位移和俯仰角的峰峰值。
5. 在不驱动本程序的前提下，如可由安全人工方式微小移动机构，确认两路读数随位置变化而变化。

通过条件：静止 30 秒内无丢帧、无突变；人工微移时计数变化方向和物理变化一致。异常时先检查编码器供电、A/B/485 接线、共地和 USB 转换器。

## 02 - 低速点动与方向确认

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_02_low_speed_jog.py"
```

操作：

1. 完成 00、01，确认独立急停可用且周围无人进入活动区。
2. 开始 CSV，勾选机械安全确认。
3. 输入例如 `5 rpm`、`0.20 s`。
4. 点击“发送正 rpm 脉冲”，观察缸位移和俯仰角的正负变化，等待完全停止。
5. 点击“发送负 rpm 脉冲”，同样记录。
6. 写下“正 rpm → 缸位移符号 → 俯仰角符号”的对应关系。

通过条件：两个方向都可控、指令结束后停止、编码器变化连续。方向与预期不一致时，停止试验，先记录真实方向；不得直接修改 MPC 的正方向约定。

## 03 - 安全可用行程测量

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_03_safe_stroke_measure.py"
```

操作：

1. 在明确的安全起始位置使用“电机位移清零”和“俯仰角清零”（若实验定义需要）。
2. 以低速短脉冲人工接近一个安全端点，在端点前保留机械安全余量，停止并等待稳定。
3. 点击“记录安全端点 A”。
4. 以同样方式靠近另一安全端点，绝不依赖程序撞击硬限位。
5. 停止并稳定后点击“记录安全端点 B”。
6. 记录显示的可用行程和俯仰范围，点击“导出端点标定 JSON”。

输出：阶段 CSV 和端点 JSON。端点 JSON 是 06 开环试验的输入之一。

通过条件：端点 A/B 的方向、位移和角度关系可重复。该结果表示**安全可用行程**，不等于机械硬限位之间的理论最大行程。

## 04 - 不同速度特性

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_04_speed_characterization.py"
```

操作：

1. 选择一个已确认安全的中间位置，避免靠近端点。
2. 从 `5 rpm`、`0.5 s` 开始，依次测试规划的 rpm 档位。
3. 每档分别点击“正方向速度试验”和“负方向速度试验”，每个组合至少重复 3 次。
4. 程序显示端点平均缸线速度和平均俯仰角速度；点击“导出最近速度结果 JSON”。

建议记录表：命令 rpm、方向、持续时间、平均 mm/s、平均 °/s、载荷、温度、重复次数。严格比较时应保持相同载荷和起始角度。

## 05 - 最小进给量

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_05_min_increment.py"
```

操作：

1. 在中间安全位置，先使用默认 `5 rpm / 0.20 s`。
2. 分别执行正、负“最小进给”。
3. 每次脉冲后等待完全停止，记录显示的 `Δ缸位移` 与 `Δ俯仰`。
4. 在确认仍有可靠响应时，逐步降低速度或缩短脉冲；每个条件重复至少 5 次。

判定：最小进给量应以“重复试验中稳定、明显大于编码器静止噪声”的最小位移/角度为准，而不是单次偶然变化。

## 06 - 开环目标角验证

启动：

```cmd
".venv\Scripts\python.exe" "MPC_fixed\lift_06_open_loop_angle.py"
```

操作：

1. 使用与 03 标定相同的电机零点和机械参考位置；若无法恢复，必须重新做 03。
2. 点击“加载 03 端点标定 JSON”。
3. 使用相同载荷、相同运动方向条件下的 04 数据，点击“加载 04 速度结果 JSON”。
4. 输入目标俯仰角。目标必须位于两个安全端点之间。
5. 点击“计算单次开环计划”，核对目标位移、当前位移、速度、方向和时长。
6. 首次只验证小区间；超过 `2 s` 的计划会被程序拒绝，不能通过放大脉冲绕过该限制。
7. 开始 CSV、勾选机械安全确认，点击“执行一次开环脉冲”。
8. 程序停止后只读取最终俯仰角，记录 `最终角度 - 目标角度` 作为开环误差。

该阶段严格不使用俯仰角对运动过程进行实时修正；俯仰编码器只用于开始前核验和结束后评价。开环误差会受到载荷、摩擦、温度、电源、间隙和速度标定误差影响。

## CSV 字段

每个阶段 CSV 均包含：

- 时间戳、测试阶段、事件、备注、命令 rpm；
- 电机/俯仰反馈是否有效；
- 电机原始计数、相对计数、缸位移、估计缸速度；
- 俯仰原始计数、相对计数、俯仰角和俯仰角速度。

CSV 默认使用 `utf-8-sig`，可直接用 Excel 打开。CSV、JSON 标定数据属于实验数据，不应提交到 Git。
